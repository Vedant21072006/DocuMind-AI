
# AI Document Assistant — Evaluation Questions

## 1. Direct factual question
Question: Ask for a fact explicitly stated in the PDF.
Expected result: The answer matches the document.

## 2. Follow-up question
Question: Ask a question that depends on the previous question.
Expected result: The assistant understands the reference correctly.

## 3. Multi-part question
Question: Ask about two or more related points in the PDF.
Expected result: The answer covers the supported parts.

## 4. Missing information
Question: Ask for information that does not appear in the PDF.
Expected result: The assistant acknowledges that the document
does not provide sufficient information.

## 5. Specific detail
Question: Ask for a particular name, number, definition, or example.
Expected result: The detail matches the source document.
